This path threads a single idea — **contiguous, addressable memory** — from the
array all the way up to a TPU pod. Each level builds on the last: arrays explain
indexed access, hash tables turn that into O(1) lookup, caching applies it to
real systems, and the TPU topology shows the same thinking at supercomputer
scale. Work top to bottom, or jump to whatever you need.
