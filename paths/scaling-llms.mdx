Two kinds of scaling have to meet for a modern LLM to train. **Mixture of
experts** scales the *model*: route each token to a few specialized experts so
parameter count grows without the per-token compute. **TPU v5p topology** scales
the *hardware*: wire thousands of chips into a 3D torus and pick a slice shape
that matches how you split the model. Read them in order — sparsity first, then
the machine that runs it — or jump straight to whichever you're sizing up.
